# Circuit Studio component catalog expansion

This update expands the exact-terminal Circuit Studio catalog with common sensors, displays, radio/network modules, actuators, drivers, passives, power modules, test tools and additional board interfaces.

The catalog is intended for prototype planning. Exact breakout revisions, clone pinouts, electrical ratings, library support and firmware behavior can differ. Generic planning entries are not build-ready components. Always verify manufacturer documentation, voltage/current budgets, protection, and physical wiring before powering a circuit. High-current, battery and mains-related work requires suitable protection and qualified supervision.

The catalog count is computed at runtime from `nexus.services.circuits.catalog()`; board entries are included.
